## 1. Bug / Toàn vẹn dữ liệu

**D1 — H ✅ Sync ghi đè cloud khi đọc thất bại.** `data/sync/GoogleDriveSyncManager.kt:300-332, 488, 610, 666`
`httpGet` trả `null` với mọi non-2xx (401/429/5xx); parse JSON lỗi cũng `null`. Khi đó `remote == null` → `buildLocalPayload(null)` upload payload chỉ của máy này, PATCH đè (hoặc tạo file trùng nếu list lỗi). Xoá sạch sách/bookmark/highlight của thiết bị khác.
→ Ném lỗi khi non-2xx/parse fail, huỷ sync; không bao giờ ghi khi chưa biết trạng thái remote.

**D2 — H ✅ Ghi index không atomic, có race, đọc lỗi = rỗng.** `data/book/BookIndexStore.kt:13-19`, `LibraryRepository.kt:176-179`; cùng pattern ở `AnnotationRepository.kt:113-132`, `ReadingStatsRepository.kt:138-148`, `reader/pdf/PdfBookConfigStore.kt:37-46`
`writeText` ghi đè trực tiếp; `read()` nuốt lỗi parse → `emptyList()`, lần commit sau lưu rỗng vĩnh viễn. `store.write` chạy ngoài lock, nhiều coroutine (lật trang, backfill cover, import, sync) ghi song song → snapshot cũ có thể thắng.
→ `AtomicFile` / temp + rename; `Mutex` bao update+write; parse lỗi thì backup file hỏng, không trả rỗng.

**D3 — H Annotation của sách không có trên máy bị xoá khỏi cloud.** `GoogleDriveSyncManager.kt:392-394, 448-473`
Merge bỏ annotation remote nếu sách không có local, payload upload chỉ dựng từ local. Máy tắt sync file sách / sách >100 MB → xoá highlight cho mọi thiết bị.
→ Giữ nguyên annotation remote có `bookContentHash` không có local.

**D4 — M Xoá không đồng bộ được (không có tombstone).**
- Bookmark/highlight: merge union theo id (`AnnotationRepository.kt:93-110`) → xoá local, sync lại hiện về.
- Sách: `deleted_cloud_book_hashes` chỉ nằm trong SharedPreferences (`GoogleDriveSyncManager.kt:76-82`), máy khác re-upload; "Xoá toàn bộ dữ liệu Drive" bị máy khác hoàn tác.
- Sign out `prefs.clear()` xoá luôn tombstone (`:176-181`) → đăng nhập lại tải về sách đã xoá. Sign out cũng không revoke quyền Drive.
- "Xoá toàn bộ cloud" thêm mọi hash local vào deleted set (`:267-271`) → thư viện hiện tại không bao giờ sync lại, không báo gì.
→ Đưa `deletedIds`/`deletedBookHashes` (+timestamp) vào `SyncPayload`; giữ tombstone khi sign out; sau wipe thì clear tombstone hoặc hỏi rõ.

**D5 — M Các lỗi sync khác.** `GoogleDriveSyncManager.kt`
- List file `pageSize=200`, bỏ `nextPageToken` (`:485`) → ≥200 sách miss file JSON → tạo trùng + kích hoạt D1.
- `uploadSyncJson` không có connect/read timeout (`:618-641`) → treo trong `mutex`, UI kẹt "đang đồng bộ".
- Một sách upload lỗi (quota/413) ném exception, chặn toàn bộ sync tiến độ (`:601`).
- `dailyGoalMinutes` merge bằng `maxOf` (`data/stats/ReadingStatsRepository.kt:114`) → hạ mục tiêu thì sync trả lại giá trị cao.

**D6 — H ✅ Reflow PDF nhiều cột trộn thứ tự.** `reader/pdf/PdfReflowEngine.kt:126`
`sortedBy { it.topFraction }` phá thứ tự cột đã sắp ở `:85-94`.
→ Giữ thứ tự đoạn, chèn ảnh theo (columnBucket, top).

**D7 — H ✅ Tone Dark: EPUB bị đảo màu 2 lần.** `reader/EInkColorFilter.kt:25-36`, `reader/EInkPreferencesMapper.kt:21-23`, `ui/reader/ReaderScreen.kt:155`
Readium đã vẽ nền #121212/chữ #EAEAEA, rồi layer `ColorMatrix` đảo lần nữa → trang gần như trắng.
→ Không áp bước invert cho view EPUB (chỉ dùng cho bitmap PDF), hoặc đưa màu sáng cho Readium khi invert.

**D8 — M Lỗi vị trí đọc.**

## 2. Hiệu năng / Pin

**P1 — H Lật trang = ghi lại toàn bộ `library.json`.** `ReaderViewModel.kt:179-181` → `LibraryRepository.kt:69-76`
Mỗi locator emit launch 1 coroutine ghi cả file và emit `books` cho mọi observer.
→ Debounce 1–2 s, flush ở `onPause`/`onCleared`; lâu dài cân nhắc Room/DataStore.

**P2 — H ✅ PDF: reflow + paginate cả sách trên main thread.** `ui/reader/PdfPagerReader.kt:211-222, 312-333`
`buildReflowPage` (gồm `PdfGraphicMasker`, O(H·V) và O(n²) — `PdfGraphicMasker.kt:100-121, 441-445`) cho mọi trang chạy trong `remember{}` khi compose; `textMeasurer.measure` từng đoạn. Chạy cả ở mode không phải reflow; chạy lại khi xoay/đổi font. → ANR với sách vài trăm trang.
→ Chỉ tính khi `HYBRID_REFLOW`, chạy `Dispatchers.Default` qua `produceState`, paginate lười quanh trang hiện tại.

**P3 — H PDF: LRU bitmap tính theo count.** `PdfPagerReader.kt:1038` `LruCache(8)`; GUIDED_COLUMN/zoom >1.35× render 2× → 30–50 MB/trang. OOM bị `runCatching` nuốt → trang trắng.
→ `sizeOf` theo byte (~1/8 `maxMemory`), giới hạn kích thước render 2×.

**P4 — H `ReaderActivity.onPause` quá nặng.** `ReaderActivity.kt:165-268`
Mỗi pause (dialog quyền, share sheet, chuyển app): đọc lại cả chương + regex strip HTML / chạy lại PdfPageAnalyzer, refresh widget, **full Drive sync** (userinfo + list + tải + upload JSON + có thể upload sách), không debounce, có thể upload tiến độ cũ.
→ Sync qua WorkManager unique job (KEEP, debounce ≥30 s, backoff), chỉ PATCH khi hash payload đổi; cache snippet theo href/page.

**P5 — H Kéo độ sáng ghi settings mỗi event.** `ReaderScreen.kt:153-161, 517-523`, `ReaderBars.kt:341`, `reader/EInkSettingsStore.kt:14-18`
Mỗi pixel: ghi lại 22 key prefs, `setLayerType` + Paint mới, Readium `submitPreferences`, `evaluateJavascript`, reset flash counter. `LaunchedEffect(nav, settings)` key theo cả object → bật footer/grain/orientation cũng resubmit.
→ Độ sáng giữ ở state tạm, persist khi thả tay; key effect theo `toEpub(settings)` + các field filter.

**P6 — H Khởi động lạnh làm hết trên main thread.** `EmptyApplication.kt:12-13`, `AppContainer.kt:15-23`
PDFBox init, Readium, đọc đồng bộ library/bookmarks/highlights/stats/pdf config/lockscreen. Chạy cả khi widget update, wallpaper start, broadcast. Widget `updatePeriodMillis=1800000` (`res/xml/eink_widget_info.xml:9`) cold-start process mỗi 30 phút.
→ `by lazy`, load async trên IO, PDFBox lazy; widget `updatePeriodMillis="0"` + refresh khi đổi ngày.

**P7 — M PDF: khác.**
- Phân tích PDFBox toàn bộ sách trước khi hiện trang đầu, không check cancel (`PdfPagerReader.kt:158-202`, `PdfPageAnalyzer.kt:20-36`) → sách 500 trang chờ hàng chục giây.
- `PdfDocumentClassifier` mở PDDocument + PdfRenderer lần 2 song song (`ReaderViewModel.kt:387-397`).
- Prefetch bitmap trang kề cả ở reflow mode, nơi không hiển thị (`PdfPagerReader.kt:336-345`).
- `vectorSegments` không giới hạn, cả sách ghi 1 file JSON, load toàn bộ mỗi lần mở (`PdfPageAnalyzer.kt:334-356`, `PdfDocumentCache.kt:28, 53`); cache ở `filesDir`, không dọn khi xoá sách.
- Region image reflow không cache, render lại mỗi lần vuốt (`PdfPagerReader.kt:876-881, 1058-1083`).
- 1 `PDFTextStripper` mỗi trang → O(N²) (`PdfPageAnalyzer.kt:115-185`).

**P8 — M Reader EPUB: khác.**
- Ghosting: mỗi lần lật alloc bitmap + `view.draw()` software trên main (`ReaderScreen.kt:182-187, 569-580`); ghost không qua color filter. → reuse bitmap, `PixelCopy`.
- `LockScreenReadingStore.saveToDisk` chạy trên Main (`LockScreenReadingStore.kt:95-104, 144-148`); `LockScreenNavReceiver` ghi file trên main, `CoroutineScope(IO)` không `goAsync()` (`LockScreenNavReceiver.kt:20-26`).
- Inject JS stroke style mỗi lần lật trang (`ReaderScreen.kt:162-168`) — chỉ cần khi đổi href.
- `isCurrentPageBookmarked` parse JSON mọi bookmark mỗi lần lật (`ReaderViewModel.kt:135-138, 240-259`).
- `progress`/`pageTurnTrigger` đọc ở đầu `ReaderScreen` → cả màn recompose mỗi lần lật (`ReaderScreen.kt:98-101`). → truyền lambda/State xuống.

**P9 — M Thư viện / Launcher.**
- `CoverBitmapCache`: LRU 64 entry không `sizeOf`, không downsample cover 360 px, copy RGB_565 → ARGB_8888 (`ui/eink/CoverBitmapCache.kt:15, 44, 51`) → tới ~50 MB cho thumbnail 48×68 dp.

- `isLiveWallpaperActive()` (binder call) gọi trong composition mỗi lần gõ search; không refresh khi resume (`LibraryScreen.kt:190-193`).
- `backfillMissingCovers` mở lại mọi sách không có bìa mỗi lần khởi động (`LibraryRepository.kt:51-66`).

**P10 — L Wallpaper / sync / dependency.**
